## Changes
- **CSP** (`app.security.csp`):
  `default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' asset: http://asset.localhost data: blob:; font-src 'self'; connect-src ipc: http://ipc.localhost`
  - **Scheme strings checked in the Tauri 2.12.7 source.** `convertFileSrc` builds `${protocolScheme}://${protocol}.localhost/`, and the scheme is `http` because `use_https_scheme` is false. So assets on Windows load from `http://asset.localhost`. `asset:` is kept for macOS and Linux.
  - **IPC observed** on `http://ipc.localhost`, with no postMessage fallback warning.
- **Test:** `csp_is_strict_except_styles` in `src-tauri/src/lib.rs`. It parses `tauri.conf.json` and asserts:
  - no `unsafe-eval`;
  - `script-src` has no `unsafe-inline`;
  - `default-src` is exactly `'self'`.
  - **RED:** adding `'unsafe-inline'` to `script-src` makes it panic. **GREEN:** it passes.
- **`tauri-plugin-opener` removed:** from `Cargo.toml`, from the `lib.rs` `.plugin(...)` call, from the `opener:default` capability, and from the npm package (`npm uninstall`, lockfile updated).
- **Font licences:** `app/src/fonts/OFL-SourceSerif4.txt` and `OFL-RedHatMono.txt`, fetched with plain `curl` from raw.githubusercontent.
  - Each file starts with a short header and then the upstream text verbatim: `adobe-fonts/source-serif` `release/LICENSE.md` and `RedHatOfficial/RedHatFont` `master/OFL.txt`.
  - `LICENSES.txt` now points to both files.
  - **Copyright mismatch:**
    - The bundled TTFs embed "© 2014 - 2021 Adobe Systems Incorporated …" and "Copyright 2024 The Red Hat Project Authors …".
