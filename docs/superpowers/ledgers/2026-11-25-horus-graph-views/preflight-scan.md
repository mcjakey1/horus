  - **BLOCK:** an implementer would build the wrong thing, fail to compile (Rust or `tsc` in `npm run build`), or break an existing test.

  - **COS:** cosmetic.
- **Counts:** **7 BLOCK, 20 REWORK, 24 COS.** Each finding has an ID (B, R or C) and is listed once, in section 6. Sections 1–5 refer to those IDs.

Tasks 9–10 assume a Plan 2 `edit`/`commit` interface without the sealed `Insert*` inverses, `touches_taxonomy` or `visible()` that review rulings added.
